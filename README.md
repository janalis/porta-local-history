# Local history — a Porta plugin

Snapshots every save and restores one as a single undoable edit.

This is `janalis/porta-local-history`, one of the plugins bundled with
[Porta](https://github.com/janalis/porta), the terminal IDE for PHP. Porta
ships it already, on by default: turn it off under **Settings → Plugins**.
Install this package only to run a copy of your own, which shadows the bundled
one.

- [Documentation](https://janalis.github.io/porta/plugins/local-history/)
- [Writing a plugin](https://janalis.github.io/porta/plugins)

## Read-only

This repository is a read-only split of `plugins/local-history` in
[janalis/porta](https://github.com/janalis/porta), updated on every push.
Report issues and send pull requests
